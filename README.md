# Vibe Coding Lab

教育現場與學校行政數位工具的實驗性原型集合。此處主要保存快速開發的網頁介面、操作概念與可行性測試，並非所有頁面都已達正式上線標準。

## 專案定位

- 校務行政流程數位化
- 教育與資訊科技應用
- 單頁式網頁工具
- AI 輔助開發與介面測試

## 使用方式

多數作品為獨立 HTML 原型，可下載後以瀏覽器開啟。若專案需要後端、資料庫或 API，應另行設定環境變數與存取權限。

## 開發原則

1. 原型與正式系統分開保存。
2. 正式使用前進行功能、權限與個資檢查。
3. API 金鑰只放在環境變數，不提交至 repository。
4. 每個成熟專案應拆分為獨立 repository，補齊安裝、部署與版本說明。

## 資料安全

本 repository 可能涉及學校行政情境，僅能使用測試或去識別化資料。不得提交學生名冊、案件紀錄、聯絡資訊或其他敏感資料。
